# When Did Global Unemployment Go Downhill?

## Overview
This project investigates a single question:

**When did global unemployment meaningfully worsen?**

Using unemployment data from 1991–2021, I identify structural turning points in global labor markets through trend analysis and year-to-year change detection.

## Key Findings
- Global unemployment shows clear downturns in **2009** and **2020**
- These years correspond to the **global financial crisis** and **COVID-19 pandemic**
- The turning points are confirmed through:
  - Global average trend analysis
  - Year-to-year change spikes
  - Cross-country comparison (US, Germany, India, Brazil)

## Project Structure
- `unemployment_analysis.ipynb` — Full analysis notebook
- `unemployment analysis.csv` — Dataset
- `requirements.txt` — Required Python packages

## Tools Used
- Python
- Pandas
- Matplotlib

## Conclusion
This project demonstrates how focused analysis and minimal preprocessing can uncover meaningful economic turning points using transparent, data-driven methods.
